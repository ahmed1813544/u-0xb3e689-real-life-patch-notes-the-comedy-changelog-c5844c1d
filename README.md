# Real-Life Patch Notes: The Comedy Changelog

A one-line software patch note for a bug in real life: walking through a
doorway wipes your short-term memory — filed as a shipped fix, with the
doorway itself named as the root cause.

`main.py` (stdlib only, deterministic) writes the patch note to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> v3.1.4: fixed a bug where walking through a doorway cleared the user's short-term memory. Root cause: the doorway.
